# Generative Galaxy

## Overview

Generative Galaxy is an algorithmic visualization project created with Processing. The program generates a unique space scene containing stars, colorful nebula clouds, planets, orbital paths, a glowing galaxy core, and an asteroid belt.

The visualization is based on a generative approach. Random values are used to create different positions, sizes, colors, and shapes each time the scene is generated. The `noise()` function is also used to create a more organic cosmic dust effect.

## Current Features

- Procedurally generated galaxy scene
- Random star field
- Colorful nebula clouds
- Glowing galaxy core
- Randomly generated planets
- Planet rings
- Planet moons
- Planet surface patterns
- Orbital paths
- Asteroid belt
- Cosmic dust generated with `noise()`
- Screenshot saving functionality

## Controls

- Press `R` to generate a new galaxy.
- Press `S` to save the current visualization as a PNG image.

Saved screenshots are stored inside the `screenshots` folder.

## Software

This project was created with:

- Processing
- Java mode

## Project Purpose

The purpose of this project is to demonstrate algorithmic visualization through a generative approach. The generated images are not manually drawn. Instead, they are produced by algorithms that use randomness and procedural rules to create multiple unique versions of the same visual concept.
